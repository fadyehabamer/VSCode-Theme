## [1.1.3] - 2026-09-24

### Fixed

- Keyboard focus is now visible: `focusBorder` was the same color as the background and is now teal `#59d5b8`.
- A selection on the current line is now visible: `editor.selectionBackground` is slate blue `#1d4560` instead of matching `editor.lineHighlightBackground`. Occurrence highlights and unfocused selections use translucent versions of the same color.
- Comments, markdown quotes and CodeLens are brighter (`#5a5a5a` to `#858585`, 4.91:1) but still dimmer than normal text.
- Line numbers are brighter (`#515151` to `#6e6e6e`, 3.55:1).
